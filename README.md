# AP Invoice Dashboard

## Overview
Power BI project for practicing — and studying for PL-300. I wanted to practice with a real-world business process I'm familiar with.

## What this is
A simple one-page Dashboard-like Power BI Desktop page that tracks a fictional company's AP invoice processing

## Files
AP_Invoice_Dashboard_PowerBI.pbix: Power Bi file — open it in Power BI Desktop
AP_Invoice_Data.xlsx: The made-up dataset behind the dashboard, with a tab explaining each column. 
screenshot: A screenshot in case you don't want to download the file

## KPIs
Total Invoices
Total Spend
PO Ratio
Average Approval Days

## What's on the dash board
Missing Documentation
Interactive Month / Department slicers
Vendor spend analysis
Invoice type comparison
Monthly trend analysis

## Tools
Power BI
Claude (to generate the sample data)

Sample data generated for portfolio purposes.
